One world, ten treatments

One artwork. Wildly different outcomes.

We brought an original Cosmic Garden illustration into Pinta Online, then added live type, a shape-tool halo, and a graphic signal line on separate layers. A flattened copy was run through the library one effect at a time. Keeping the subject fixed turns the grid into a visual control experiment: every image differs only by the tool it demonstrates.

  • UntreatedImported art, ellipse, line, live text
  • Hexagon PixelateA mosaic from an add-in
  • Ink SketchGraphic-novel linework
  • Chromatic AberrationChannels split by 14px
  • ScanlinesCRT ruling
  • Colored Artifacts128 seeded blocks
  • PosterizeThree levels per channel
  • Invert ColorsThe negative print
  • Night VisionGreen response plus grain
  • Oil PaintingBrush size and coarseness

Five of these ship switched off. Hexagon Pixelate, Chromatic Aberration, Scanlines, Colored Artifacts and Night Vision come from bundled add-ins you enable in the Add-in Manager — which is how the grid was made, and how you would make your own.

Good to know

Questions, answered.

Is Pinta Online free?

Yes. The editor at paint.rip is free to use and does not require an account.

Are my images uploaded to a server?

No upload step is used for editing. Files are decoded, composited, transformed, and exported in your browser. Workspace restoration is stored locally in your browser’s IndexedDB on that device.

Can it preserve layers?

Yes. OpenRaster import and export preserve layer names, visibility, opacity, blend modes, ordering, and pixel data. PNG, JPEG, WebP, BMP, TIFF, PPM, and TGA exports produce composite images.

Does it use the original Pinta shortcuts?

Yes. Pinta accelerators such as Ctrl/Command+N, O, S, W, R, and the original tool keys are captured by the editor while appropriate text-editing shortcuts remain native to focused fields.

How is this related to desktop Pinta?

Pinta Online is a React browser edition based on Pinta 3.2. It reuses Pinta’s native artwork and interaction vocabulary, while the original C# and GTK application remains available from the upstream Pinta project.

Can I install it?

Yes. A supported desktop or mobile browser can install Pinta Online as a Progressive Web App. Once cached, its interface can start offline; opening new local files does not require a network connection.
